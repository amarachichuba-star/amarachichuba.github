# Eileen Amarachi Chuba | Portfolio

Personal portfolio website of **Eileen Amarachi Chuba**, a second-year Computer Science (Data Science and AI) student at the University of Dundee with a growing interest in machine learning, artificial intelligence and software development.

**Live site:** https://amarachichuba-star.github.io/My-portfolio/

## What's on the site

- **About me:** a short introduction and my skills grouped into languages, tools, concepts and soft skills.
- **Experience:** an interactive journey of my education, leadership roles, hackathon and tutoring, with a detail card for each and a 2025 to 2030 timeline.
- **Projects:** my work laid out along a swirling path, including a small playable Battleship-style grid.
- **Contact:** email, LinkedIn, GitHub and a downloadable CV.

## Built with

- HTML, CSS and vanilla JavaScript in a single `index.html`, with no frameworks or build step
- Google Fonts: Fraunces, Instrument Sans and JetBrains Mono
- Custom data-style cursor with live coordinates and a fading trail, plus a notebook-grid background that lights up around the cursor
- Responsive layout, keyboard-accessible controls, and reduced-motion support

## Run it locally

No installation needed. Download or clone the repo and open `index.html` in a browser.

```bash
git clone https://github.com/amarachichuba-star/My-portfolio.git
cd My-portfolio
open index.html   # or just double-click the file
```

The site is hosted with GitHub Pages, served from the `main` branch. Any change committed to `index.html` goes live within a couple of minutes.
